# Arcwright — AI capability

Human-authored narrative runtime middleware with deterministic session facilitation.

This repository was generated by **team-ai**. It holds this team's owned
knowledge base, its scoped agents, deterministic scripts, and an eval harness.
It is an *instance*: the framework ships the structure, this repo holds the
content.

## Layout

| Path | What it holds |
|---|---|
| `kb/` | The knowledge base — markdown with front matter, one folder per namespace. |
| `agents/` | The router (`sme`) and the domain and role subagents. |
| `agents/manifest.fragment.yaml` | This instance's domains. `assemble-manifest` merges it into `manifest.yaml`. |
| `manifest.yaml` | Generated. The full routing table the router reads. Do not hand-edit. |
| `skills/` | Fixed tool-sequence skills (`kb-answer`, `kb-contribute`, `audit-summary`, `sme-route`). |
| `personas/` | Tone-only personas. They grant no access. |
| `evals/` | `gates.yaml` thresholds and the `golden/` question set. |
| `index.lock` | The retrieval build contract. Changing a value forces a full reindex. |

## Day to day

These commands use the team-ai CLI built from source. It is not published to
npm, so install it by cloning github.com/nickejanssen/team-ai and running
`npm ci`, `npm run build`, and `npm link` under Node 22. See that repository's
README.
```bash
team-ai validate-kb            # front matter + relations
team-ai assemble-manifest      # rebuild manifest.yaml from the fragment
team-ai reindex                # rebuild the retrieval index
team-ai run-evals              # replay the golden set against the gates
team-ai freshness-audit        # list stale / orphaned / unowned docs
```
