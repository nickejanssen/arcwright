# Archived Nightcap Story Bibles

These files preserve the former Nightcap Story Bible authorities for provenance and design history.

**ARCHIVED — NOT CURRENT NIGHTCAP DESIGN AUTHORITY.**

Current Nightcap design authority begins at `docs/gdd/nightcap/README.md`, with the decision ledger at `docs/gdd/nightcap/00-governance/00-decision-ledger.md` taking precedence over older Nightcap gameplay decisions when they conflict.

The archived bibles remain useful for tracing prior Couch Race and Imposter designs and for understanding historical implementation decisions. An archived `Current`, `Accepted`, or `DECIDED` label describes the state at the time it was written; it does not override the current GDD.
