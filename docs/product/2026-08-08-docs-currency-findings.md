# Docs Currency Findings, 2026-08-08

External review of the docs tree against repo state. Records what is verified
correct, what is stale, and what work is deferred. Companion to ADR-0023.

## Structural finding

The execution layer is current and internally consistent. The explanation layer
is stale.

`nightcap/couch-race.arc.json`, the ADRs, `docs/story-bibles/nightcap-couch-race.md`,
`docs/roadmap/index.json`, and the task files agree with each other on player
count, beat structure, mini-game bindings, the Leverage effect catalog, and the
killer-is-an-AI-suspect model. Agents implementing from specs and ADRs are
working from good information.

What is stale is the material that explains the project to an arriving reader:
the repository root `README.md` and `docs/prd/`. Both were written in May 2026
and never revisited, because nobody implements from them.

## Root cause of recurring drift

Four patterns, in descending cost:

1. Contradictory source-of-truth declarations. A file told agents where
   authority lives, and disagreed with `AGENTS.md`. Only `AGENTS.md` and
   `docs/README.md` should do that.
2. Amendment-indirection. Correcting a doc with an errata note instead of
   editing the body forces every reader to apply a substitution.
3. Derived records maintained by hand, drifting, then disagreeing with each
   other. This produced the three-way ownership conflict that required
   ADR-0019, ADR-0020, and ADR-0021 to resolve, and the stale task statuses
   PR #277 corrected.
4. Plan documents that cannot start, aging against a moving mainline, as
   ADR-0021 notes.

   no new dependency.

   so agents know to re-verify rather than trust.

   approval per `AGENTS.md` Hard Rules.
