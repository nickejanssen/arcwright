# Adversarial Pass 01

**Verdict:** PASS WITH CONSTRAINTS

## Exploits tested

Reward snowballing; evidence pooling; kingmaking; hoarding; alliances;
lying; dogpiling; minigame sandbagging; hopeless-player states; alpha
quarterbacking; Heat farming; Counterintel farming; espionage-only play;
minigame domination; always-spy strategy.

## Findings

-   Persistent reward engines are dangerous → **big swings, short
    half-life**.
-   Mechanically merged alliance Case Files are dangerous → **Knowledge
    ≠ Proof**.
-   Free human cooperation/lying should remain; individual victory
    creates natural tension.
-   Dogpiling needs systemic cost → Heat/Counterintel is a TESTING
    direction.
-   Higher minigame placement should not have lower expected strategic
    value than intentionally placing worse.
-   Preserve recoverability without manufacturing parity.
-   Alpha-player quarterbacking remains a real-play test risk.

## Result

No conceptual exploit required abandoning the architecture. Most fixes
are constraints on existing systems rather than new systems. Real-player
testing is still required.
