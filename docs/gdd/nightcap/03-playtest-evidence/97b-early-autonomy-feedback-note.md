# Nightcap — Early Autonomy Feedback Note

**Status:** TEST FINDING / supporting evidence — not canon  
**Provenance:** creator-reported early qualitative feedback; participant count and detailed fixture conditions are not specified in this checkpoint.

## Reported signal

Players responded positively to:

- autonomy,
- reaching their own conclusions,
- using their own deduction rather than feeling hand-held through the investigation.

## Interpretation

This directionally supports the current design preference for high perceived autonomy and player-owned inference.

It does **not** prove that maximum openness is better. Paper Test #2 v2.1 also produced **Mostly Confusing** action clarity from an independent tester, so Nightcap still needs to validate the balance between autonomy and understandable actionability.

## Evidence rule

Treat this as supporting TESTING evidence, not as a permanent law. Representative gameplay feedback may strengthen, refine, or reverse the resulting design choices.
